# サンタ、ちゃんと届けて — 設計

2026-10-04 確定。元資料は本人の「サンタ配達ゲーム 制作設定資料」（17章）。この文書は、元資料で未決定だった項目への答えと、作り方を決めたもの。

## 1. 一言で

異常にジャンプ力が高いサンタが、雪の夜の街を飛び回り、理不尽な世界を乗り越えてプレゼントを届ける 3D アクション。プレイ時間は 10〜20 分。

一番大事なのは「サンタを操作しているだけで面白い」こと。まず移動・ジャンプ・配達の手触りを完成させ、その後に理不尽ギミックを足す。

## 2. 決めたこと（本人の選択）

| 項目 | 決定 |
|---|---|
| 視点 | 三人称（後ろから）。切り替えはなし |
| 見た目 | コードで組む（箱・円柱の組み合わせ）。外部モデルは使わない |
| 端末 | PC＋スマホ |
| 街 | 1 つのつながった街。配達先が順に奥へ進む |
| 技術 | three.js＋自作の当たり判定。物理ライブラリは使わない |

## 3. 遊びのルール

| 項目 | 内容 |
|---|---|
| ジャンプ | 高さ固定、最高点 約14m（家の屋根 約6m を軽く越える）。押す長さで高さは変わらない |
| 着地の目印 | サンタの真下の地面・屋根に影を落とす。高いところにいても着地点が分かる |
| 空中制御 | 弱め。入力で向きは変えられるが勢いが残る |
| ダッシュ | なし |
| 配達 | 目的の家の煙突の上で E（スマホは配達ボタン）。煙突の上にいるときだけ有効 |
| プレゼント | 1 種類。常に持って移動する（拾う操作は受け取り地点で E） |
| 落とす条件 | ギミックに当たる、穴や街の外へ落ちる |
| リトライ | その配達の受け取り地点に戻り、プレゼントを持った状態でやり直し |
| 配達先 | 5 軒。住宅街 → 商店街 → 公園 → 高架 → 最後の家 |
| ギミック配分 | 1 軒目はなし（操作を覚える）。2 軒目以降、1 軒につき 1〜2 個ずつ増える |
| 制限時間 | なし。クリア時に合計タイムと自己ベストを表示（localStorage、読めなければ表示しないだけ） |
| クリア | 5 軒すべて配達 |

数値（高さ・重力・空中制御・移動速度など）はすべて `src/10-config.js` の `CFG` に集め、遊んでもらいながら調整する。

### 操作

- PC：WASD 移動／マウスで視点（クリックでポインタロック）／Space ジャンプ／E 拾う・配達
- スマホ：画面左に移動スティック／右側のドラッグで視点／ジャンプボタン／配達ボタン

## 4. 理不尽ギミック（仮）

元資料の例（巨大な穴、突然現れる壁、巨大化するプレゼント、月が落ちてくる、家が逃げる、魚が降る、道路がスケートリンクになる、無限に続くドア、巨大な目）は**候補**で、中身と順番は Phase 6 の時点で本人と決め直す。そのときも元資料 9 章の方針（意味不明な現象と、プレイヤーが取れる対処をセットにする）は守る。

Phase 1〜5 はギミックの中身に依存しないように作る。具体的には、ギミックが「プレゼントを落とさせる」「当たり判定の箱を出し入れする」「サンタの滑りやすさを変える」といった操作を、`70-gimmicks.js` から呼べる関数として用意しておく。

## 5. 構成

本体: `C:\Users\PC_User\Second brain\santa\`（独立 git、`master`）。Node は無いので、`src/` を `sh build.sh` で結合する。

| ファイル | 役割 |
|---|---|
| `00-head.html` / `99-tail.html` | HTML の外枠、three.js の読み込み（CDN）、画面の UI |
| `10-config.js` | 数値 `CFG` |
| `20-sound.js` | 効果音（Web Audio で自作） |
| `30-world.js` | 街を作る。見た目のメッシュと当たり判定の箱（AABB）を同時に登録 |
| `40-santa.js` | 移動・ジャンプ・着地・影の目印 |
| `45-camera.js` | 三人称カメラ（壁や屋根にめり込まない） |
| `50-input.js` | キーボード・マウス・タッチ |
| `60-delivery.js` | プレゼント・配達先・リトライ・タイム |
| `70-gimmicks.js` | 理不尽ギミック（Phase 6 から） |
| `90-boot.js` | 起動・タイトル・クリア画面 |

出力: `santa.html`（本体）／`index.html`（GitHub Pages 用のコピー）／`verify.html`（自動確認）。

当たり判定は、街がすべて箱なので AABB 同士の判定で済ませる。サンタも箱として扱い、軸ごとに動かして押し戻す。上からの着地は「屋根の上に乗る」、横からは「壁で止まる」。屋根の三角の部分は見た目だけにして、当たり判定は平らな箱（乗れる面）にする。

## 6. 確かめ方

- `verify.html`: ジャンプの最高点が CFG どおりか、屋根・煙突に着地できるか、壁を抜けないか、煙突の上でだけ配達が成立するか、落下でリトライ地点に戻るか、などを自動で確かめる
- 見た目はアプリ内ブラウザで描画し、スクリーンショットで確認する

## 7. 進め方

各 Phase の終わりに本人が遊んで OK を出してから次へ進む。

1. 基本移動：雪の夜の小さな一画、三人称カメラ、PC とスマホの操作
2. 高ジャンプ：影の目印、屋根・車に乗る
3. プレゼントを持つ：落とす・リトライ
4. 配達：煙突で E、5 軒の街、タイム
5. 簡単な障害：電線・穴など現実寄りのもの
6. 理不尽ギミック（中身はこの時点で決め直す）
7. 街全体の調整、GitHub Pages で公開

## 8. やらないこと

ストーリー、戦闘、敵、複数のプレゼント種類、視点切り替え、ダッシュ、外部 3D モデル、物理ライブラリ。
